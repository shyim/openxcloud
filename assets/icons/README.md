# App icon

Generated with the built-in image generation tool. `openxcloud-source.png` is the
original; numbered PNG files are resized exports preserving transparency.
`@2x` exports contain twice the named pixel size for Retina displays.
The 256px image is embedded in the desktop window; cargo-bundle uses all sizes for
macOS and Linux package icons. Regenerate exports with `sips -z SIZE SIZE` on macOS.

## Generation prompt

Use case: logo-brand. Asset type: production desktop app icon for OpenXCloud, a native cloud gaming app. Generate one square 1024x1024 icon, straight-on, no mockup. A beautifully proportioned dark charcoal rounded-square tile with a bold luminous lime green cloud symbol; a crisp right-pointing play triangle cut out of the cloud as dark negative space. Simple memorable silhouette, confident geometric curves, restrained soft dimensional lighting and subtle bevel on the green mark, premium macOS app aesthetic. Centered composition, generous breathing room inside tile; tile occupies about 88% of canvas, smoothly rounded corners. Actual transparent background outside the tile. Palette matches a charcoal and electric lime gaming interface. Must read clearly at 32px. No text, letters, Xbox logo, controller details, decorative particles, watermark, or scene. One icon only.
